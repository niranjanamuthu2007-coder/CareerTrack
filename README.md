# CareerTrack

CareerTrack is a student placement preparation and job application tracking platform.

## Project Overview

CareerTrack is designed to help students organize their placement preparation journey in one platform.

Students will be able to:

- Track DSA problems
- Manage job applications
- Track technical skills
- Create study tasks
- Monitor preparation progress
- View analytics
